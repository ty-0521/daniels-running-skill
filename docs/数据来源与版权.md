# 数据来源与版权

这份说明原先附在 `LICENSE` 末尾。放在这里，是因为 GitHub 的许可识别器看到
MIT 正文后面还接着别的段落，会把整个仓库标成「Other」——而它其实是 MIT。
许可本身没有变：代码按根目录的 [LICENSE](../LICENSE) 授权。

## 什么是原创的

代码、方程实现、规则摘要、误差统计、解释词条、边界声明，均为本项目原创，MIT 许可。

## 什么不在仓库里

《丹尼尔斯经典跑步训练法（第3版）》的正文、表格图片、清洗后的全文，
**一律不进仓库**，也不出现在任何 API 响应里。`explain` 的答案是对书中论述的改写，
不是引用；书里的原句不进代码。

## 仓库里的数值分两类

1. 由 Daniels–Gilbert 回归方程计算得出；
2. 原书正文中可以直接读到的算例，仅作为测试真值与误差校验使用。

## 引用

每条规则、每个词条都标注章号与行号（行号一律由 `daniels.citations.cite()` 给出），
读者需自行持有原书核对。本仓库不提供原文，也不提供原文的替代品。
