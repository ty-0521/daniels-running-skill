## 三、推送

先在 GitHub 上建一个**空仓库**（不要勾 README、不要勾 .gitignore、不要选 license），然后：

```bash
git remote add origin https://github.com/<你的用户名>/daniels-running-skill.git
git push -u origin main
```

推完去 `Actions` 看第一次 CI。Linux 四档 Python + Windows 一路，全绿才算发成。

## 五、发之前再想一遍这句话

这份东西能承诺的不是「不会错」，是**「错了你能当场看见」**。

十四条实测里它每一个错都被抓出来，原因不是它诚实，是每个数都能拿回去核——
方程、规则号、或者你自己说过的话。

**把这个性质写进 README 的第一屏，比写「准确率 99%」诚实，也更有说服力。**
